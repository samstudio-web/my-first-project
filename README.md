# Premium Graphic Designer Portfolio

A responsive, single-file portfolio starter for GitHub Pages.

## Before publishing
Open `index.html` and replace:
- `YOURNAME` and `Your Name` with your display/brand name
- `you@example.com` with your email
- Instagram and Behance URLs with your real profile links
- The four sample project cards with your real project names and artwork

The artwork cards are CSS-based sample concepts, not real client projects. Replace them with your own work before presenting the portfolio professionally.

## Publish with GitHub Pages
1. Create a public repository on GitHub (for example `portfolio`).
2. Upload `index.html` and `README.md` using **Add file → Upload files**, then commit.
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait a few minutes and refresh the Pages section. GitHub will show your live website URL.

If the repository is named `yourusername.github.io`, the site URL is usually `https://yourusername.github.io/`. For another repository name, it is usually `https://yourusername.github.io/repository-name/`.
